ScreenQuizSolver Configuration & Guide

Quick Setup

All settings are securely stored in Chrome's encrypted local sync storage (chrome.storage.sync) and are configurable directly from the extension popup icon in your Chrome toolbar.

Supported Providers

Provider Key Format API Key Source Mode
Groq (Recommended) gsk_... console.groq.com Ultra-fast text reasoning
Google Gemini AQ... aistudio.google.com Multimodal (Text + Vision)
OpenRouter sk-or-v1... openrouter.ai Free open-source vision/text models

Keyboard Shortcuts

  • Alt + S — Trigger instant screen scan & answer computation
  • Alt + H — Show or hide the bottom answer bar
  • CopyQ — Click the CopyQ button in the overlay bar to copy the extracted question even on sites that block copy actions

Security & Privacy

ScreenQuizSolver operates with zero intermediary tracking or external backend servers. Requests are dispatched directly from your browser to your selected AI provider using your configured API key.
